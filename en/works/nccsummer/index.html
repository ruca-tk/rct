01

Context

New Context Conference is Digital Garage's annual technology conference. I have designed every NCC event site since 2019 — up to three editions per year, across Tokyo and San Francisco. Each year starts the same way: a theme title, a logo, and a key visual. Everything else is mine to define. This edition's theme was "Zen AI and Blockchain."

02

Direction

The key visual for this edition showed a meditating figure seated at the edge of a cosmic portal — warm amber and dusty rose against deep space blue. I used it as the foundation for everything. The colour palette was extracted directly from the illustration, and the ambient, contemplative tone it established shaped the register of the entire site: not a loud tech conference, but something more considered and philosophical.

To maintain visual consistency beyond the provided key visual, I generated supporting images using AI to match the same ambience — used in the break sections and the registration CTA. The goal was a site that felt like one world from top to bottom.

03

Key Decisions

01. Palette from the Key Visual Rather than designing a colour system independently, I pulled the palette directly from the provided illustration — warm ambers, dusty roses, and deep blue-greys. This keeps the site and the event visual in the same emotional register. When someone sees the poster and then visits the site, it feels like the same world.

02. AI-Generated Supporting Imagery The key visual established a specific aesthetic that stock photography couldn't match. I generated additional images using AI to fill the break sections and footer CTA while staying true to the illustration's tone. This approach maintains cohesion across the full page without pulling in visually mismatched filler.

03. Dynamic Speaker Loading The NCC speaker lineup changes frequently — names are confirmed late, order shifts, profiles update right up to the event. I moved the speaker data into a JavaScript object and render the cards dynamically rather than hardcoding them in HTML. Adding or reordering a speaker is now a single-line change in a data file. This is something I introduced this year and will carry forward across future NCC editions.

04

Design

The site reads dark and immersive — deep backgrounds, warm accent tones, generous spacing. The key visual anchors the hero and reappears at the registration section, closing the page with the same visual weight it opened with. The speaker grid, agenda, and host sections follow a consistent card system throughout.

The bilingual structure — Japanese primary, English available — reflects the conference's domestic focus while remaining accessible to an international audience.

05

Build

Built with Vite, Tailwind CSS, GSAP, Lenis, and vanilla JS — the same stack I use across all NCC event sites. The speaker section is data-driven: each speaker is defined as a JavaScript object with name, title, image path, and session data, then rendered into the DOM on load. Updating the lineup requires no changes to the HTML.

06

Outcome

The site launched for the June 2025 event and continues a visual language I have been developing for NCC since 2019 — each edition a distinct identity built from its theme, but part of a recognisable series. The dynamic speaker system is a structural improvement that makes every future NCC site faster to manage.

07

Reflection

The AI image generation worked well for supporting imagery, though in a few places the generated images are slightly inconsistent in texture with the provided key visual — close, but not exact. Next time I would establish a more precise generation brief upfront rather than iterating toward something that looks close enough. A tighter brief produces a more consistent result.
